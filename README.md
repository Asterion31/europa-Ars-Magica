# Europa MCCXX

Carte de l'Europe vers 1220 pour une campagne d'Ars Magica.

- Carte des joueurs : l'adresse GitHub Pages du dépôt.
- Lieux révélés : `data/places.json`. Pour révéler de nouveaux lieux, remplace le contenu de ce fichier par la « version joueurs » copiée depuis la vue MJ, puis valide (Commit changes). La carte se met à jour en une minute environ.
- Vue MJ locale : ajoute `#mj` à la fin de l'adresse. Les lieux créés là restent dans ce navigateur seulement.

Sources : relief, côtes, fleuves et noms géographiques de Natural Earth (domaine public). Frontières vers 1200 de aourednik/historical-basemaps (GPL-3.0), ajustées à la main pour 1220 et approximatives. Leaflet 1.9.4 (BSD-2-Clause).
